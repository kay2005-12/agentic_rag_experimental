# 📱 Flipkart Mobile Agentic RAG — Testing Version

An experimental Agentic RAG project built to test document retrieval, conditional routing, and LLM-based question answering on Flipkart mobile phone data.

## 🧪 Project Status

**Status:** Experimental / Testing Phase

This repository contains an initial implementation for testing core Agentic RAG components. It serves as a foundation for a larger project that will include additional features and improvements.

## 🎯 Current Objectives

- Test LangGraph-based agentic workflows.
- Experiment with document retrieval and filtering.
- Explore FAISS vector search and BM25 keyword retrieval.
- Generate answers using an LLM through Groq.
- Test structured queries on mobile phone specifications.

## 🛠️ Tech Stack

- Python
- LangChain
- LangGraph
- Groq
- FAISS
- BM25
- Typesense

## 🔍 Current Experiments

- Document loading and metadata handling.
- Conditional retrieval and answer generation.
- Hybrid retrieval experiments.
- Attribute-based filtering, such as finding phones with a specific battery capacity.
- Testing retrieval coverage across the loaded dataset.

## 📊 Dataset

The current testing setup uses mobile phone data extracted from `Flipkart Mobile - 2.pdf`.

The document collection currently contains **430 documents**.

## 🚧 Future Development

This is an early testing version. Further development will focus on improving retrieval accuracy, query understanding, workflow design, evaluation, and the overall user experience.

More features will be added as the larger project evolves.
